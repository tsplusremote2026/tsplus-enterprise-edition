Security & Best Practices

``` ```

Administrative scripts should be reviewed and tested before being used on production systems.

``` ```
Never store passwords, API keys, authentication tokens, private certificates, license keys, or other sensitive information in this repository.
``` ```
``` ```

Least Privilege

Run administrative utilities with only the permissions required for the intended task.

``` ```

Test First

Validate scripts and configuration changes in a development or test environment before production use.

``` ```

Protect Credentials

Keep credentials and sensitive configuration outside source control.
